# Syphon Filter PC 0.1.0-public-test.29

Windows x64 public-test candidate built on 2026-08-13.

## Changes since public-test.28

- Restored sequential PS1 ordering-table traversal and removed the custom
  chunk-stencil/depth-clear system that could reveal distant scene details
  through foreground walls.
- Extended connected-route rendering with transactional texture admission and
  dense retail fog, while refusing incomplete resource suffixes.
- Added optional mission skyboxes with a persistent launcher toggle and
  original SCRIM/fog fallback when disabled.
- Added oriented fire/smoke volumes, display-rate particle interpolation,
  high-resolution retail-derived fire animation, authored halo colour and
  wall-aware dynamic lights.
- Corrected Girdeux's flamethrower trajectory and added bounded surface
  illumination along the retail ribbon.
- Improved indexed-texture minification, GMD fallback normals and world-object
  shadow presentation.
- Refactored and localized the Windows launcher and fixed settings persistence.
- Restored the sniper scope's complete 320x160 black mask; rifle optics hide
  the ordinary HUD and restore it immediately on exit.
- Kept failure/death information messages visible above letterbox framing.

## Validation

- Windows x64 PsyCross Release build completed successfully.
- Full Release CTest suite completed successfully.
- Source diff and release archive audits completed without forbidden files.
- The interactive game was not launched during automated validation.

## Package

- Windows x64 release with required runtime libraries, Russian locale, dossier
  screens and all runtime mission skyboxes.
